# Lessons

## 2026-08-10 — Don't start implementing without an explicit go

Started M0 (TeX bundle analysis) right after Eshaan confirmed a design detail.
Confirming a design question is not approval to build. Wait for an explicit
"go" / "start" before writing or running anything that produces deliverables.

Research and measurement to answer a question he asked is fine. Moving to the
next milestone is not.

## 2026-08-10 — Check volume before offering a filter option

Offered "watchlist companies only" as a notification option without measuring
it first. Real answer: 0 alerts in the last 7 days for 15 hot startups. The
option was useless and he picked it. Should have run the numbers before
putting it on the menu.
